# How Many Tabs Do You Have Open?

My honest answer: **47 tabs** open in my browser right now.

This entry is a tiny program that writes that count — digits only, nothing
else — to `/output/entry.txt`. Forty-seven tabs is a lived-in number: enough
open research, half-read articles, docs, and "I'll get back to this" pages
that the browser has become a second memory, but still a count a real person
could genuinely have open.
